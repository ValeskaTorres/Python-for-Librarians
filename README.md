# 📚 Library Python Project

An introductory **Python** project developed in Google Colab, using a library context to practice fundamental programming concepts.

The project was developed based on the material *Python for Librarians*, by librarian Fabiana Santos, and uses situations related to library routines to transform basic programming concepts into practical exercises.

## 🎯 Objective

The objective of this project is to develop and consolidate fundamental **Python** programming skills by relating programming concepts to situations within the field of Library Science, such as:

* book registration and identification;
* author and publication year information;
* loan management;
* tracking loan status;
* user interaction;
* calculation of overdue fines.

## 🛠️ Technologies and Concepts

* **Python 3**
* **Google Colab**
* Variables and data types
* Strings
* Integers and floating-point numbers
* Boolean values
* Conditional statements (`if / else`)
* Lists
* For loops (`for`)
* User input with `input()`
* String formatting with **f-strings**
* Mathematical operations

## 📖 About the Project

The notebook begins with exercises involving the creation and use of variables, using book-related information such as title, author, publication year, and availability.

The project then explores situations related to **book loans**, including user identification, loan duration, and return status. Conditional statements are used to determine different responses according to the loan situation.
The project also includes exercises with **lists and loops**, allowing multiple book titles to be stored and iterated through.

## 💻 Final Exercise: Circulation Desk

As a practical exercise, a small **library circulation desk system** was developed.

The program asks the user to provide:

1. User's name;
2. Book title;
3. Number of overdue days;
4. Daily fine amount.

Based on this information, the program generates a loan summary and automatically calculates the fine when the book is overdue.

### Example

```text
CIRCULATION DESK
User name: Juliana
Book title: 1984
Days overdue: 5
Daily fine amount: $ 2

SUMMARY
User: Juliana
Book: 1984
Status: 5 day(s) overdue.
Estimated fine: $ 10.00
```

This exercise demonstrates how basic programming concepts can be applied to solve a practical problem related to the management and circulation of library materials.
